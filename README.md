# Tejaswi Anand Portfolio

Personal portfolio website for showcasing projects, certifications, and technical writing. 

Live URL: [thisistejaswi.in](https://thisistejaswi.in)

## Overview

A responsive, grid-based portfolio built to present information clearly and efficiently.

## Technology Stack

- Next.js
- React
- Tailwind CSS

## Local Setup

1. Clone the repository:

```bash
git clone https://github.com/anandtejaswi/portfolio-card-design.git
cd portfolio-card-design/nextjs-portfolio
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Directory Structure

- `app/`: Routing and main pages
- `components/`: UI components and grid widgets
- `content/`: Markdown files for project descriptions
- `config/`: Configuration for layouts and site metadata
- `public/`: Static files like images and documents
